# codeAlpha_stock_portfolio_tracker
A simple Stock Portfolio Tracker that helps users manage and monitor their investments. It allows users to add stocks, track shares and prices, calculate portfolio value, and view overall profit or loss in an easy-to-use interface.Track and manage your investments effortlessly with real-time portfolio value and profit/loss insights.

# Features of Stock Portfolio Tracker 
1.Add & remove stocks – Portfolio mein stocks add/remove kar sakte hain.

2.Track stock prices – Stocks ki current price monitor kar sakte hain.

3.Portfolio value – Total investment/value calculate hoti hai.

4.Profit & Loss – Overall profit ya loss easily calculate hota hai.

5.Investment tracking – Quantity, purchase price aur investment details maintain hoti hain.

6.Simple interface – Easy-to-use aur beginner-friendly design.

# Description
📊 Track your stock investments easily.
